# Projetos (exemplo fictício)

> Dados inventados para teste e demonstração. Não descrevem nenhuma pessoa real.

## Projeto Agenda Fácil

Aplicativo web de agendamento para pequenas clínicas, feito com Node.js, Express e PostgreSQL. A pessoa cadastrou horários, pacientes e lembretes por e-mail. Escreveu testes de API com Jest e publicou a aplicação com Docker.

## Projeto Robô de Conferência

Automação em Node.js com Playwright que abre um portal de notas fiscais fictício, baixa os arquivos do mês e confere os totais em uma planilha do Google Sheets. Reduziu a conferência manual de duas horas para dez minutos.

## Projeto Painel de Vendas

Painel em React e TypeScript que consome uma API REST e mostra gráficos de vendas por região. Usou Git e GitHub, revisão de código em pares e integração contínua com GitHub Actions.
